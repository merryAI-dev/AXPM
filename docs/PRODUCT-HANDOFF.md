# AXPM 멘토링 운영 시스템 업데이트 안내

안녕하세요. AXPM 멘토링 운영 시스템입니다.

이번 업데이트는 기존 Google Drive와 사업관리 마스터 시트를 그대로 사용하면서, 반복적으로 확인하고 옮겨 적던 멘토링 운영 업무를 줄이는 데 초점을 맞췄습니다.

멘토는 기존 보고서의 회차 탭에 내용을 작성하고, 운영자는 AXPM에서 반영 결과와 누락 항목을 확인할 수 있습니다. 자동으로 처리된 기록은 별도의 활동 이력에 남으며, 원본 보고서가 변경되었을 때도 운영자가 확인한 뒤 안전하게 되돌릴 수 있도록 구성했습니다.

현재 사용할 수 있는 주요 기능을 소개합니다.

## 사업 운영 대시보드

사업관리 마스터 시트의 핵심 현황을 AXPM 홈에서 바로 확인할 수 있습니다.

- 전체 참여 기업 수
- 전담 멘토링 완료 회차
- 특화 멘토링 완료 현황
- 보고서 작성일 미기입 건수
- 캠퍼스별 진행 현황
- 원본 마스터 시트 바로가기

대시보드는 별도 데이터를 만들어 보여주는 방식이 아니라, 설정된 사업관리 마스터 원본을 다시 읽어 최신 현황을 표시합니다.

## 멘토링 보고서 자동 반영

멘토가 기존 보고서 파일에 정해진 회차 탭을 만들고 필수 내용을 작성하면 AXPM이 해당 보고서를 확인합니다.

자동 반영을 위해 다음 항목을 함께 검사합니다.

- `1회차`부터 `4회차`까지의 정해진 탭 형식
- 기업명과 캠퍼스
- 멘토명
- 실제 멘토링 일자
- 보고서 작성일
- 참석자와 멘토링 본문 등 필수 내용
- 사업관리 마스터의 기업 및 담당 멘토 일치 여부
- 같은 보고서가 이미 반영되었는지 여부

검증을 통과하면 사업관리 마스터의 해당 회차 완료 여부와 보고서 작성일을 기록합니다. 회차가 이미 완료되어 있고 작성일도 정상이라면 다시 쓰지 않습니다.

예약 정보, 파일명, 빈 회차 탭만으로는 완료 처리하지 않습니다. 필수값이 누락되거나 기업과 멘토가 정확히 연결되지 않으면 자동 반영하지 않고 확인이 필요한 이유를 표시합니다.

## 수정 및 삭제에 대한 역방향 반영

자동 반영이 끝난 뒤 멘토가 회차 탭을 삭제하거나 필수 내용을 지우면 AXPM이 변경을 감지합니다.

이 경우 마스터를 즉시 지우지 않고 승인 대기함에 원복 제안을 만듭니다. 운영자가 내용을 확인하고 승인하면 해당 자동 반영이 작성했던 셀만 되돌립니다.

자동 반영 이후 사람이 직접 수정한 값이나 다른 회차의 기록은 지우지 않습니다. 원본 보고서와 마스터가 서로 다른 상태가 되었을 때 운영자가 최종 판단할 수 있도록 설계했습니다.

## Drive 폴더 탐색 및 검색

운영 대상 Drive 폴더를 AXPM에서 바로 탐색할 수 있습니다.

- 관리 폴더와 하위 폴더 열람
- 폴더 구조 조사
- 조사한 전체 파일명 검색
- 새 폴더 생성 변경안
- 파일 이름 변경, 복사, 휴지통 이동 및 복원 변경안
- Google Sheets와 XLSX 원본 열기
- 승인 후 지정 셀 수정

Drive 원본을 변경하는 작업은 먼저 변경안으로 저장됩니다. 운영자는 작업 이력에서 대상과 내용을 확인한 뒤 승인할 수 있습니다.

## 최근 24시간 Drive 변경

AXPM 접속 시 관리 폴더의 최근 변경 메타데이터를 확인합니다.

- 최근 수정된 파일
- 이름이 변경된 파일
- 위치 또는 버전이 변경된 파일
- 변경 확인 시각

홈 화면에는 최신 50건을 표시합니다. 이 기록은 Drive 파일의 변경 흐름을 확인하기 위한 것으로, 문서 내부의 모든 셀 수정 내역을 의미하지는 않습니다.

## 보고서 파일명 표준화

보고서 파일명과 보고서 본문, 사업관리 마스터의 기업 정보를 함께 비교해 표준 파일명 변경안을 만듭니다.

파일명만으로 기업을 확정하지 않으며, 보고서 본문과 마스터에서 기업이 하나로 확인된 경우에만 변경 대상으로 분류합니다. 같은 폴더에 동일한 이름이 있거나 캠퍼스 정보가 충돌하면 실행하지 않습니다.

운영자는 변경 전후 이름을 확인한 뒤 일괄 적용할 수 있습니다. 파일명 변경 과정에서 보고서 본문은 수정하지 않습니다.

## 운영 에이전트

Gemini 기반 운영 에이전트가 AXPM의 실제 조회 및 자동화 도구를 사용합니다. 필요에 따라 Hermes를 실행기로 연결할 수 있습니다.

에이전트는 다음 업무를 수행할 수 있습니다.

- 사업관리 마스터 현황 조회
- 기업별 완료 회차와 보고서 누락 확인
- 관리 Drive 폴더 및 파일 조사
- 특정 보고서의 회차 탭과 필수값 확인
- 보고서 자동 반영 상태 조회 및 실행
- 파일명 표준화안 생성 및 적용
- 확인된 멘토링 기록의 마스터 반영

마스터 기록은 먼저 변경될 셀을 계산한 뒤 같은 계획으로 실행합니다. 정기 조사는 조회와 보고서 감시만 수행하며 임의로 마스터 값을 작성하지 않습니다.

## 활동 및 작업 이력

자동화와 운영자 작업은 각각 이력으로 남습니다.

- 자동 반영된 기업과 회차
- 실제 변경된 마스터 셀
- 변경 전후 값
- 보고서 점검 결과와 제외 이유
- 역방향 반영 제안과 승인 결과
- 에이전트 요청과 응답
- Drive 변경안의 승인 및 실행 상태
- 실행 실패 또는 결과 확인이 필요한 작업

변경 사항이 없는 정기 조사는 활동 목록에 반복해서 쌓이지 않습니다. 실제로 파일을 확인했거나 반영·오류·보완 사항이 발생한 실행을 중심으로 표시합니다.

## 계정 및 접근 권한

Firebase Google 로그인을 사용하며, 허용된 회사 도메인 또는 개별 운영 계정만 업무 화면과 API에 접근할 수 있습니다.

Google Drive와 Sheets는 서버의 운영 서비스 계정을 통해 연결합니다. 서비스 계정은 지정된 관리 폴더 안에서만 파일을 조회하거나 변경할 수 있으며, 폴더 밖의 파일과 바로가기 외부 대상에는 접근하지 않습니다.

Gemini API 키와 정기 실행 비밀은 서버의 Secret Manager에 보관합니다. 브라우저와 공개 설정 응답에는 비밀값을 전달하지 않습니다.

## 운영 흐름

1. 멘토가 기존 보고서 파일의 회차 탭에 멘토링 내용을 작성합니다.
2. AXPM이 탭 형식과 필수값, 기업, 멘토, 날짜를 확인합니다.
3. 검증된 내용만 사업관리 마스터에 자동 반영합니다.
4. 홈 대시보드가 마스터 원본을 다시 읽어 진행 현황을 갱신합니다.
5. 자동 반영 결과와 근거가 활동 이력에 남습니다.
6. 보고서가 삭제되거나 불완전해지면 승인 대기함에 원복 제안이 생성됩니다.
7. 운영자는 예외 항목과 승인 대기 작업만 확인합니다.

## 운영 준비 상태

Google Drive와 사업관리 마스터 연결, Firebase 로그인과 데이터 저장, Gemini 비밀 저장, 자동 보고서 감시, 비공개 백업 저장소와 배포용 컨테이너 저장소가 준비되어 있습니다.

배포 전 점검에서는 결제 연결, 필수 Google Cloud API, 실행 서비스 계정, Firestore, 비공개 파일 버킷, Artifact Registry, Secret Manager와 Google 로그인이 모두 확인되었습니다.

실제 서비스 배포 후에는 배포 주소를 Firebase 승인 도메인에 추가하고, 허용 계정으로 로그인하여 마스터 조회와 보고서 자동 반영을 최종 확인하면 됩니다.

이번 업데이트를 통해 멘토는 기존 양식을 바꾸지 않고 보고서를 작성하고, 운영자는 반복 입력보다 누락과 예외 확인에 집중할 수 있습니다. AXPM은 원본 Drive와 마스터 시트를 중심으로 자동 반영, 검증, 승인, 이력 확인이 하나의 흐름으로 이어지도록 지원합니다.
