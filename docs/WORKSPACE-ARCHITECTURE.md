# Drive 워크스페이스

환경변수로 지정한 Google Drive 루트와 사업관리 마스터가 업무 원본이다. 앱은 Firebase에 조사 체크포인트, 자동 반영 이벤트, 승인 상태와 작업 이력을 저장한다.

모든 Drive 요청은 로그인 사용자와 서버 접근 정책을 검사한 뒤 서비스 계정으로 실행한다. 대상 파일이 관리 루트의 하위 항목인지 매 요청마다 확인하며 shortcut, 루트 자체 변경, 오래된 버전 쓰기를 거절한다.

XLSX 변경은 원본 버전과 변경 전 셀을 확인하고 비공개 백업을 만든 뒤 지정 셀만 수정한다. Google Sheets 변경도 동일하게 셀 값과 버전을 확인하고 실행 후 다시 읽는다. 이름 변경, 복사, 폴더 생성, 휴지통 이동과 복원은 Firestore 작업으로 기록한다.

폴더 조사는 한 번에 한 페이지를 처리하고 체크포인트를 저장한다. 최근 변경 파일과 재시도 대상 보고서를 먼저 읽으며 전체 폴더가 끝날 때까지 다음 실행에서 이어간다. 검색은 조사 완료된 메타데이터 인덱스를 사용한다.

에이전트는 Drive 조사, 보고서 셀 읽기, 변경 미리보기와 승인된 실행에 같은 서버 함수를 사용한다. 정기 실행 키에는 조회 권한만 부여한다.
