---
name: axpm-report
description: 실제 멘토링 메모를 AXPM 원본 엑셀 보고서의 9개 셀 필드로 정리해 검토 가능한 초안으로 저장한다.
---

사용자는 원본 XLSX의 지정 셀에 값을 채우는 결과를 원한다. 유사한 HTML·새 엑셀 양식을 만들지 않는다. 그림 좌표나 bbox를 추정할 필요가 없다.

`axpm_company`로 기업명·대표자·담당 멘토를 확인한 뒤, 실제 메모를 다음 필드로 정리해 `axpm_report_draft`에 전달한다.

| 필드 | 내용 | 기본 셀 |
| --- | --- | --- |
| company | 기업명 | C3 |
| representative | 대표자 | E3 |
| mentor | 담당멘토 | C4 |
| datePlace | 일시 및 장소 | E4 |
| attendees | 참석자 | C5 |
| topic | 멘토링 주제 | C6 |
| companyStatus | 기업현황·이슈 | B9 |
| discussion | 논의사항·멘토 제안 | B11 |
| nextPlan | 다음 일정·논의 주제 | B13 |

운영 콘솔에서 매핑을 바꿨다면 변경된 매핑이 우선한다. 내용에는 메모에서 확인된 사실과 제안을 구분한다. 없는 참석자·일시·성과를 만들지 말고 확인 필요로 표시한다. 완료 체크만으로 논의 내용을 작성하지 않는다. 회사명이 메모와 원본에서 다르면 확인한다.

초안 저장 후 운영 콘솔에서 검토·저장·다운로드하도록 안내한다. 다운로드는 원본의 지정 셀 XML만 교체한다. 원본에 기존 사진이 있으면 유지되므로 해당 보고서에 맞는 사진인지 확인한다.
