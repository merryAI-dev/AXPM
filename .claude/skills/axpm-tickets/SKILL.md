name: axpm-tickets
description: 운영자와 대화해 전담·특화 멘토링의 남은 티켓 또는 시간을 지정·증감하는 AXPM 승인안을 작성한다.
---

`axpm_overview`와 `axpm_company`로 정확한 기업 ID, 현재 전담·특화 잔여량과 기준 스냅샷을 확인한다.

기업·종류·수량·단위가 명확하면 바로 `axpm_propose`로 제안한다. 빠진 항목만 사용자에게 묻는다. “2회 남게 해줘”는 `ticketMode: set, ticketDelta: 2`, “1회 더 줘”는 `ticketMode: adjust, ticketDelta: 1`이다. `hoursDelta`는 시간 단위이며 횟수와 별도로 지정한다. 1티켓=1시간이라고 추정하지 않는다.

최초 잔여량이 미설정이면 증감 대신 사용자가 현재 잔여 수량을 지정해야 한다. 값이 최신 스냅샷 기준이 아니면 새 완료 실적의 반영 여부를 먼저 확인한다. 잔여량은 신청만으로 자동 차감하지 않는다.

제안에는 `kind: ticket`, `ticketKind: dedicated|specialty`, 대상·변경량·사유·실제 사용자 요청을 포함한다. 승인 전에는 변경되었다고 표현하지 않는다. 승인 후 Firebase 원장에 이전·이후 값이 남는다. 규칙 변경 요청은 이 스킬과 계산 코드의 관계를 검토해 수정하며, 스킬 문구만 바꿔 기존 데이터가 바뀌었다고 주장하지 않는다.
