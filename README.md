# AXPM

멘토링 횟수 모니터링과 기업지원서비스 정산 업무의 에이전트화 가능성을 검토하는 프로젝트.

## 현재 상태 — 2026-09-16

- 기존 업무는 Apps Script와 Claude를 활용한 것으로 추정되며, 실제 파일과 코드 확인이 필요하다.
- 사용자가 이후 업무 파일을 제공할 예정이다. 구현 및 플랫폼 선정은 아직 하지 않았다.
- Hermes Agent 등을 후보로 검토한다.
- 작은 작업 단위로 커밋·푸시하고, 작업 종료 시 원격과 동기화한다.

## 초기 설계 가설

| 업무 | 자동화 후보 | 사람이 판단할 부분 |
| --- | --- | --- |
| 멘토링 모니터링 | 실적 수집, 기업·멘토별 횟수 집계, 목표 대비 부족·중복·증빙 누락 탐지, 안내 초안 | 실적 인정 예외, 외부 안내 승인 |
| 기업지원서비스 정산 | 제출서류 분류, 증빙 간 항목 대조, 규정에 따른 금액 계산, 누락 목록·검토안 작성 | 규정 해석 예외, 정산 확정·지급 승인 |

횟수 집계와 금액 계산은 검증 가능한 코드로 처리하고, 에이전트는 문서 해석·도구 호출·후속 작업 조율을 담당하는 구조를 우선 검토한다. 기존 Apps Script는 재사용 가능성을 확인한다. 위 내용은 실제 업무 파일 확인 전 가설이다.

## 확인한 외부 자료

- [Block Q4 2025 공식 발표 — Jack Dorsey](https://s29.q4cdn.com/628966176/files/doc_financials/2025/q4/Q4-2025-Prepared-Remarks-Block.pdf): AI를 회사 운영과 의사결정의 중심에 두겠다는 방향을 제시한다. 본 프로젝트 업무의 자동화 성과를 입증하는 사례는 아니다.
- [Nous Research Hermes Agent 공식 저장소](https://github.com/NousResearch/hermes-agent): 예약 실행, 지속 메모리·스킬, MCP 연동을 제공한다고 설명한다. 반복 점검과 업무 도구 연결의 후보이며, 실제 데이터 연동과 정확도 검증이 필요하다.
- [Hermes Agent 공식 문서](https://hermes-agent.nousresearch.com/docs/)

## 파일 수령 후 검토

1. 기존 시트·Apps Script·프롬프트와 실제 처리 사례를 통해 입력부터 완료까지의 흐름을 복원한다.
2. 횟수 인정 기준, 정산 규정, 예외와 승인 절차를 확인한다.
3. 기존 방식 유지·보완과 에이전트 도입의 비용, 정확도, 운영 부담을 비교한다.
4. 멘토링 점검을 우선 시범 적용할지 실제 업무량과 오류 영향을 보고 결정한다.
5. 기존 완료 사례와 결과를 대조해 집계 정확도, 누락 탐지, 정산 금액 일치, 담당자 소요 시간을 평가한다.

현재 저장소는 공개 저장소다. 실제 개인정보·증빙 원본·인증정보는 커밋 대상에 포함하지 않고, 코드와 비식별 예제로 작업한다.
